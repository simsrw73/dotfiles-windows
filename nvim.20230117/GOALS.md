# Goals

A list of informal design goals to guide the selection of plugins.

- Choose plugins that use the same base libraries. eg. nui, plenary
- Consistent UI
- UI consistent with the way Vim works. Eg bufferline vs tabby
- Should use the same keystroke consistent with Vim rather than trying to be like Windows, etc. Eg no super tab
- Established plugins. Eg been around for a while, plenty of commit activity
- Large community for support
- Active development
